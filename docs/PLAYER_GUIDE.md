# Open RTS

## Install and start

Extract the whole archive before launching. Keep the executable, `assets/` and
the other supplied files together.

- **Windows:** open `launch.cmd`.
- **Linux:** run `./launch.sh` from the extracted folder.

The packaged game does not require Rust or Nix. Saves and settings use your user
data folder, so the installation can remain read-only.

## Your first match

Choose **Boot Camp** to learn gathering, construction, production and combat.
Choose **Campaign** for missions, or **Skirmish** to select a map, factions,
players and difficulty. Read the objective panel: mission victory conditions
differ.

Send Workers to nearby deposits, build power and keep training replacements.
Protect your Command Center and power supply. Tanks attack ground targets;
Rocket Infantry and Anti-Air Turrets counter aircraft. Place defenses where
enemy approaches enter their range. Engineer Drones can capture your Command
Center; cover their flight paths with anti-air before they reach it.

## Controls

- Left-click to select; drag a box to select several units.
- Right-click ground to move, enemies to attack, or deposits to gather.
- Hover command icons for costs, requirements and shortcut keys.
- Use the **Attack-Move** icon or its displayed key for an armed advance.
- Use the arrow keys or move the pointer to the screen edge to pan.
- Use the wheel to zoom and **[ / ]** to rotate the view.
- **Ctrl+1–9** assigns a control group; **1–9** recalls it.
- **Esc** opens the match menu. In desktop offline matches, click **Save/Load**
  or use **Ctrl+S/Ctrl+L**. Saving replaces the previous quicksave.
- **F10** pauses the battle while accepting orders; press it again to resume.

Use **Options** to adjust language, fullscreen and audio. Campaign completion
and Boot Camp graduation persist separately from the current match save.
