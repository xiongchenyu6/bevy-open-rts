# Steam client-icon candidates

The256×256 shortcut PNG and184×184 application JPEG compose the original Open
RTS wordmark with a close crop of the original generated key art. Both actual
sizes were inspected for readable lettering and a recognizable foreground tank.
Two independent exports produce identical bytes.

Regenerate with `python3 art/steam/generate_icons.py /new/output-directory`.
[Manifest](manifest.json) retains input/tool/output hashes; [review](review.json)
records the visual scope. Actual client placement and final rights review remain
open. These files have not been uploaded or installed into the game.
