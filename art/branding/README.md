# Original Open RTS wordmark

The title follows the existing in-game heading. Letter paths are authored here,
without external fonts or artwork, under the repository's MIT OR Apache-2.0 terms.

Run `python3 art/branding/generate.py /new/output-directory` with resvg0.48.1.
The630×110 wordmark and transparent1280×230 library-logo candidate reproduce
byte-for-byte across two fresh runs. Full-size and126/189px light/dark samples
have been visually inspected. Manifests retain generator, SVG and PNG hashes.

The logo uses a wide aspect ratio and contains only the title. Steam requires
a transparent library logo1280px wide and/or720px tall, with client placement
chosen during preview. See [Steam library assets](https://partner.steamgames.com/doc/store/assets/libraryassets),
checked2026-10-10. Steam-client placement and final capsule compositions remain
unverified; nothing is uploaded or installed as a runtime replacement.
